Este projeto apresenta a reformulação de um relatório de vendas no Power BI, com foco em otimizar a experiência do usuário, a organização visual e a interatividade dos dashboards.

O objetivo principal foi aprimorar o relatório existente aplicando boas práticas de design e visualização de dados, tornando a análise comercial mais intuitiva, estruturada e eficiente.

 ## Objetivos do Projeto

*Otimizar a disposição e o alinhamento dos elementos visuais.

*Ajustar contraste e proporção entre os componentes do relatório.

*Inserir segmentadores de dados para tornar as análises mais dinâmicas.

*Desenvolver indicadores e gráficos focados na rápida interpretação dos resultados.

*Implementar botões e recursos de navegação intuitiva entre as páginas.

*Padronizar a identidade visual de todo o relatório.
